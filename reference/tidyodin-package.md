# tidyodin: Tidy Output from 'odin2', 'dust2' and 'monty'

Converts the arrays produced by 'dust2' simulations and particle
filters, and the samples produced by 'monty', into long-format tibbles
ready for plotting with 'ggplot2'. Also runs an 'odin2' model over many
parameter sets, returning an object with the same structure as a set of
'monty' samples.
