# Package index

## Tidy simulations

Output from running a dust2 system or particle filter

- [`tidy_simulation()`](https://mrc-ide.github.io/tidyodin/reference/tidy_simulation.md)
  : Tidy the output of a dust2 simulation
- [`tidy_filter()`](https://mrc-ide.github.io/tidyodin/reference/tidy_filter.md)
  : Tidy the trajectories from a particle filter

## Tidy samples

Output from monty, or from the functions below

- [`tidy_pars()`](https://mrc-ide.github.io/tidyodin/reference/tidy_pars.md)
  : Tidy the parameters from a set of monty samples
- [`tidy_density()`](https://mrc-ide.github.io/tidyodin/reference/tidy_density.md)
  : Tidy the log density from a set of monty samples
- [`tidy_trajectories()`](https://mrc-ide.github.io/tidyodin/reference/tidy_trajectories.md)
  [`tidy_state()`](https://mrc-ide.github.io/tidyodin/reference/tidy_trajectories.md)
  [`tidy_snapshots()`](https://mrc-ide.github.io/tidyodin/reference/tidy_trajectories.md)
  : Tidy trajectories saved alongside monty samples
- [`summarise_trajectories()`](https://mrc-ide.github.io/tidyodin/reference/summarise_trajectories.md)
  : Summarise tidy trajectories across draws

## Run many parameter sets

- [`run_parameter_sets()`](https://mrc-ide.github.io/tidyodin/reference/run_parameter_sets.md)
  : Run a model over many parameter sets
- [`continue_parameter_sets()`](https://mrc-ide.github.io/tidyodin/reference/continue_parameter_sets.md)
  : Continue a simulation from the end of a fit or a previous run
